# Agents

## Instructions

- Use and interpret "must", "must not", "required", "shall", "shall not",
  "should", "should not", "recommended", "may" and "optional" in accordance to
  RFC 2119, but in lowercase.
- Code style:
  - Favor elegance, idiomaticity and conciseness in your code.
  - Observe and adopt the existing conventions and code style.
  - Write only useful and concise comments.
  - Use the following comment prefixes:
    - Explain code whose purpose is unclear -> no prefix
    - Important info -> `NOTE:` / `WARNING:`
    - When to finish a work or remove a workaround -> `TODO:`
    - Bug/ugly code that should be fixed later -> `FIXME:`
  - Big structural changes to the code require approval.
