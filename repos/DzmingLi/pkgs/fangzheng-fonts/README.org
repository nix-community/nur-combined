#+title: fangzheng-fonts

NUR 包属性及 derivation 的 pname 均为 =fangzheng-fonts=；包目录由 =NEU-S10-fonts= 更名。该包最初名为 =cn-exam-fonts=。

统一提供 12 个字体文件，保留独立 TTF，不合成 TTC，不修改字体内部名称或字形。

* 中文字体

- 方正书宋简体（FZShuSong-Z01S）
- 方正黑体 GBK（FZHei-B01）
- 方正楷体简体（FZKai-Z03S）

* NEU S92 字体

- NEU-BZ-S92.TTF
- NEU-BZ-S92 Italic.ttf
- NEU-BZ-S92 Bold.ttf
- NEU-BZ-S92 Bold Italic.ttf

这四款字体保留 =NEU-BZ-S92= 家族及其四种样式。

* MPS 科技符号字体

- 方正科技符号_MPS.ttf
- 方正科技符号_MPS_Italic.ttf
- 方正科技符号_MPS_Bold.ttf
- 方正科技符号_MPS_Bold_Italic.ttf
- 方正科技符号_Extra_MPS.ttf

前四款保留 =FZSTS_MPS= 家族及其四种样式；Extra 字体保持独立的 =FZS_Extra_MPS= 家族。

* 来源与使用

原有书宋、黑体继续从已有 =cn-exam-fonts-1.0.0= Release 读取；历史下载地址保持有效，不随包属性改名。其余十个原始文件位于 =fonts/=，逐字节保留用户提供的文件。

覆盖层中的 NixOS 字体包引用为 =fangzheng-fonts=；通过 NUR 使用时为 =nur.repos.DzmingLi.fangzheng-fonts=。

本包只提供原始字体，不包含试排中生成的数学适配字体。安装原始字体本身不增加 OpenType MATH 布局支持。
