# Changelog

All notable changes to the `jaiganesh6999.seowebchecker` Ansible Collection will be documented here.

## Release 1.0.0

### Major Changes
- Initial release of `jaiganesh6999.seowebchecker` on [Ansible Galaxy](https://galaxy.ansible.com/).
- New action module `jaiganesh6999.seowebchecker.seo_audit` for on-page SEO health scoring and checks.
- Deployment quality gate enforcement with `min_score` and `fail_on_alert`.
- Included role `jaiganesh6999.seowebchecker.agent` for automated cron scheduling and report paths.
- Included role `jaiganesh6999.seowebchecker.quality_gate` for deployment verification playbooks.
- Official platform integration with [https://seowebchecker.com/](https://seowebchecker.com/).
