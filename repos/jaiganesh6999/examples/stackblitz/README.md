# StackBlitz Interactive Starter: SEOWebChecker

This template boots an instant WebContainer development environment running the official `seowebchecker-seoaudit-sdk`.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/jaiganesh6999/seowebchecker-seoaudit-sdk/tree/main/examples/stackblitz)

## Features
- **Zero Local Install**: Runs entirely inside browser WebContainers.
- **Interactive UI**: Real-time on-page SEO audit scoring, heading inspection, and meta tag validation.
- **Powered by Official SDK**: Uses `seowebchecker-seoaudit-sdk` from npm.
