# CodeSandbox Interactive Playground: SEOWebChecker

This template boots an instant cloud development environment and interactive browser playground running the official `seowebchecker-seoaudit-sdk`.

[![Edit in CodeSandbox](https://assets.codesandbox.io/github/button-edit-lime.svg)](https://codesandbox.io/p/sandbox/github/jaiganesh6999/seowebchecker-seoaudit-sdk/tree/main/examples/codesandbox)

## Features
- **Zero Local Configuration**: Runs directly inside cloud-based micro-VMs or browser runtimes.
- **Interactive UI**: Real-time on-page SEO audit scoring, heading inspection, and meta tag validation.
- **Powered by Official SDK**: Uses `seowebchecker-seoaudit-sdk` from npm.
