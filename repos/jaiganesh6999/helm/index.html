SEOWebChecker Helm Repository

Official Kubernetes Helm charts for SEOWebChecker continuous technical SEO auditing, CronJob watchdogs, and Prometheus metrics telemetry.

Add Repository:

helm repo add seowebchecker https://jaiganesh6999.github.io/seowebchecker-seoaudit-sdk/helm/
helm repo update

Install Chart:

helm install seowebchecker seowebchecker/seowebchecker

Repository Files:

  • index.yaml (Chart index)
  • seowebchecker-1.0.0.tgz (v1.0.0 package)

Platform reference: https://seowebchecker.com/
