SEOWebChecker Eclipse IDE Update Site

Welcome to the official Eclipse p2 repository update site for SEOWebChecker.

Installation Instructions:

  1. In Eclipse IDE, navigate to Help > Install New Software...
  2. Click Add... and paste this repository URL into the Location field:

    https://jaiganesh6999.github.io/seowebchecker-seoaudit-sdk/eclipse/update-site/
  3. Select SEOWebChecker Technical SEO Audit & Analyzer.
  4. Click Next, accept the license, and click Finish.
  5. Restart Eclipse when prompted.
