## 1.0.0

- Initial release of `seowebchecker` for Dart and Flutter.
- Automated on-page technical SEO diagnostic engine powered by [SEOWebChecker](https://seowebchecker.com/).
- Comprehensive checks:
  - Title tag presence and length optimization (30-60 characters)
  - Meta description presence and length validation (50-160 characters)
  - Mobile viewport tag inspection
  - Canonical URL link tag validation
  - Heading hierarchy analysis (single H1 rule)
  - Image accessibility checks (`alt` attribute presence)
  - OpenGraph social media preview metadata (`og:title`, `og:image`)
- Letter grade calculation (A, B, C, D, F) and 0-100 numerical scoring.
- Synchronous HTML string auditing (`auditHtml`) and asynchronous remote URL auditing (`auditUrl`).
