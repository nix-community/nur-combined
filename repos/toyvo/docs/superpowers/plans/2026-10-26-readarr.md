# Readarr Migration Implementation Plan

**Goal:** Readarr serves from k3s (local-path sqlite + RW NFS media), data seeded from verified-live set, container retired.

**Architecture:** Extend `nixcfg.k3sStarr` with readarr (StatefulSet + Service + Ingress + media PVC on existing `pool-media-rw`); Caddy upstreams flip; manual seed + verify + retire.

**Tech Stack:** NixOS (`services.k3s.manifests`), linuxserver/readarr pinned `develop-0.4.18.2805-ls157` (PUID/PGID 352), Traefik Ingress, Caddy multi-upstream.

**Spec:** `docs/superpowers/specs/2026-10-26-readarr-design.md`

## Global Constraints

- SQLite on local-path ONLY, `nodeAffinity: nas`; media via existing `pool-media-rw` (no new PV).
- PUID/PGID = 352/352 (nixpkgs readarr ids).
- Manifests from nas ONLY (single-writer rule).
- Seed ONLY from a verified-live set (`.backup` + `integrity_check` + count); never a blind top-level copy; container never restarted mid-migration.
- Old container service stays up until k8s instance verified (UI library match + split-brain reachability + pod write test); full download deferred by decision.
- qBittorrent save path already `/mnt/Downloads` (set during Radarr) — no new qbit changes; client re-test validates the shared geometry for a fourth app.
- Allow minutes for manifest propagation after switch; delete stale pods rather than waiting.
- `nix fmt` before commit; validation is eval + toplevel builds; switches + seeding + in-app reconfig are manual, nas-then-router.

## Review Focus

- Wrong UID (write failures, ownership drift) — expect PUID/PGID env == 352; test in Task 1 pins it.
- Media mount missing/wrong (no library access) — expect `/mnt` backed by `readarr-media` on `pool-media-rw`; test in Task 1 pins it.
- Pod scheduled off-nas (affinity typo) — expect pod on nas only; test in Task 3 pins it.
- Seeded from stale/wrong files (empty library, onboarding wizard) — expect book count to match pre-migration count; test in Task 3 pins it. Extra weight: container runs nixpkgs readarr, not linuxserver — no version to match.
- Retire-before-proof (split-brain breakage) — ordering enforced: disable only after UI + split-brain + write test all green; test in Task 3 pins it.
