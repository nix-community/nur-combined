# Immich Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Immich serves from k3s (server + ML + Postgres + Valkey, v3.3.6 pinned), all photos/metadata carried over via dump + rsync, container retired.

**Architecture:** New `nixcfg.k3sImmich` module (Postgres StatefulSet on local-path + Valkey cache + server + ML, NFS RW library PV, Traefik Ingress); `homelab.nix` upstreams flip removes the edge route; manual seed + verify + retire.

**Tech Stack:** NixOS (`services.k3s.manifests`), `ghcr.io/immich-app/immich-server:v3.3.6` + `immich-machine-learning:v3.3.6` + `ghcr.io/immich-app/postgres:<3.3.6-tag>` (vectorchord) + `valkey/valkey:8-alpine` (all hub/ghcr-verified), secretspec `DB_PASSWORD`, Traefik Ingress.

**Spec:** `docs/superpowers/specs/2026-11-14-immich-design.md`

## Global Constraints

- All data carries over; downtime accepted, dual-run forbidden (stop-old → seed → verify-new).
- Postgres on local-path ONLY (`nodeAffinity: nas`); Valkey cache-only (emptyDir or 1Gi local-path); library on NFS RW PV (never local-path).
- Exact version pin v3.3.6 across server + ML + NixOS `pkgs.immich` 3.3.6 (no migration risk); Postgres tag matches the upstream 3.3.6 release (ghcr-verified).
- Manifests from nas ONLY (single-writer rule; k3sEdge + app Ingresses both deploy from nas).
- Seed ONLY from verified-live container state (`pg_dumpall` + rsync library/cache); container untouched until dump day.
- `DB_PASSWORD` never in the Nix store (secretspec alias discipline, `refs.kube` pinned).
- `forwardAuthGate = false` unchanged (native Authentik OIDC rides with the DB dump).
- Allow minutes for manifest propagation after switch; delete stale pods rather than waiting.
- `nix fmt` before commit; validation is eval + toplevel builds; switches + seeding + in-app checks are manual.
- POOL state dirs never deleted in this plan.

## Review Focus

- Two servers sharing one library (k8s writes thumbs while container live) — expect server/ML at `replicas: 0` until container stopped; test in Task 1 pins it.
- Postgres on NFS (locking/corruption) — expect local-path claimTemplate, never `nfs-pool`; test in Task 1 pins it.
- `DB_PASSWORD` in the Nix store (secret leak) — expect only `valueFrom.secretKeyRef`, no literal; test in Task 1 pins it.
- Upload-path mismatch (NixOS `/var/lib/immich` vs upstream `/usr/src/app/upload`) — expect PVC mounted at the upstream path with `IMMICH_MEDIA_LOCATION` matching; test in Task 1 pins the mount.
- Stale seed (empty DB, onboarding wizard, zero faces) — expect row counts to match live before flip; test in Task 3 pins it.
