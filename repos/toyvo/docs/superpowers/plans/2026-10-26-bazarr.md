# Bazarr Migration Implementation Plan

**Goal:** Bazarr serves from k3s (local-path sqlite + RW NFS media), data seeded from verified-live set, Sonarr/Radarr API links repointed to k8s URLs, container retired.

**Architecture:** Extend `nixcfg.k3sStarr` with bazarr (StatefulSet + Service + Ingress + media PVC on existing `pool-media-rw`); Caddy upstreams flip; manual seed + verify + retire.

**Tech Stack:** NixOS (`services.k3s.manifests`), linuxserver/bazarr pinned `v1.6.2-ls369` (PUID/PGID 350, hub-verified), Traefik Ingress, Caddy multi-upstream.

**Spec:** `docs/superpowers/specs/2026-10-26-bazarr-design.md`

## Global Constraints

- SQLite on local-path ONLY, `nodeAffinity: nas`; media via existing `pool-media-rw` (no new PV — add per-app `bazarr-media` PV up front, PVs bind 1:1).
- PUID/PGID = 350/350 (nixpkgs bazarr ids).
- Manifests from nas ONLY (single-writer rule).
- Seed ONLY from a verified-live set (`.backup` + `integrity_check` + count); never a blind top-level copy; container never restarted mid-migration.
- Old container service stays up until k8s instance verified (series list populated via Sonarr/Radarr APIs + split-brain reachability + pod write test).
- qBittorrent save path already `/mnt/Downloads` — Bazarr downloads nothing, no qbit interaction.
- Allow minutes for manifest propagation after switch; delete stale pods rather than waiting.
- `nix fmt` before commit; validation is eval + toplevel builds; switches + seeding + in-app reconfig are manual, nas-then-router.

## Review Focus

- Wrong UID (write failures, ownership drift) — expect PUID/PGID env == 350; test in Task 1 pins it.
- Media mount missing/wrong (library scan finds nothing) — expect `/mnt` backed by `bazarr-media` on `pool-media-rw`; test in Task 1 pins it.
- Pod scheduled off-nas (affinity typo) — expect pod on nas only; test in Task 3 pins it.
- Seeded from stale/wrong files (empty config, onboarding wizard) — expect series/movies populated in UI via Sonarr/Radarr links; test in Task 3 pins it.
- Sonarr/Radarr URLs still pointing at container localhost (silent link failure) — expect in-app settings to show public k8s URLs; test in Task 3 pins it.
- Retire-before-proof — ordering enforced: disable only after UI + API links + write test all green; test in Task 3 pins it.
