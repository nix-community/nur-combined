# Euro-Office Docs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Euro-Office Document Server serves from k3s (pinned v9.3.1, JWT-secured) integrated with Nextcloud via a hand-built connector app, with open/edit/save round-trips proven.

**Architecture:** New `nixcfg.k3sOffice` module (Deployment + Service + Ingress, local-path PVCs, memory-backed /dev/shm, /healthcheck probes); connector app built once on nas and seeded into the existing `nextcloud-state` claim; `occ` wiring quartet; no retire, no flip (greenfield vhost).

**Tech Stack:** NixOS (`services.k3s.manifests`), `ghcr.io/euro-office/documentserver:v9.3.1` (ghcr-verified), Traefik Ingress, `eurooffice-nextcloud` app (git tag, npm + composer build).

**Spec:** `docs/superpowers/specs/2026-11-14-office-design.md`

## Global Constraints

- Exact version pins recorded verbatim (image `v9.3.1`; connector git tag recorded at build).
- JWT secret generated (32+ chars), shared DS env ↔ connector occ setting; never baked, never auto-generated.
- `EXAMPLE_ENABLED` stays off (verified off); `ALLOW_PRIVATE_IP_ADDRESS=true`; `JWT_HEADER=Authorization` both sides.
- Manifests from nas ONLY (single-writer rule); no NFS anywhere in this stack.
- Single replica, nodeAffinity nas; `nix fmt` before describe; eval + toplevel builds; switches + seeding + occ + in-app checks are manual. Commits via `jj describe`.
- No Collabora resurrection; no OnlyOffice; office.diekvoss.net needs no DNS action (wildcard).

## Review Focus

- JWT mismatch (DS secret vs connector setting — silent until first save) — expect admin green check + successful save round-trip; test in Task 3 pins it.
- DS unreachable from browser (DNS/TLS) — expect `office.diekvoss.net` loads; test in Task 3 pins it.
- DS can't POST back to Nextcloud (StorageUrl wrong/unreachable, private-IP refused) — expect save works (proves callback path); test in Task 3 pins it.
- Example app exposed (no auth on it) — expect `/example/` dead; test in Task 3 pins it.
- Auto-generated secret desync after pod recreate — expect pairing survives a pod delete + green check stays green; test in Task 3 pins it.
