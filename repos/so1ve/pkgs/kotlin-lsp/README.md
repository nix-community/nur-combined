# Kotlin LSP

The official JetBrains Kotlin language server, packaged for x86_64 and aarch64
Linux. Start it with `intellij-server --stdio`.

The server is extracted from the official `JetBrains.kotlin-server` extension on
Visual Studio Marketplace.

The distribution contains proprietary components, so Nix requires permission for
the `kotlin-lsp` unfree package.
