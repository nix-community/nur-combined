    Full Capability Suite

    Simple on day one. Unstoppable on day hundred.

    🔍

    Apps, Files, Recent & Ripgrep

    Fuzzy-launch apps ranked by favorites and usage. Pinned Search File and Recent views stay separate from main search, with image thumbnails, ~/.spotlightignore, Tab file actions, and live streaming ripgrep content search.

    Search FileRecentrg rustin: notes
    🧮

    Calculator, Units, Currency & Language

    Evaluate math expressions with trig/powers/percentages, convert units offline, fetch daily currency rates via Frankfurter, look up English definitions, translate words offline with FreeDict, and view inline tldr cheat sheets.

    10 km to mi100 USD to AUDdefinetldr tar
    📝

    Quick Notes, Obsidian, Todos & Snippets

    Capture Markdown notes from anywhere with automatic Obsidian vault detection. Manage checkbox tasks in todos.md, and expand trigger snippets (;sig) inside Spotlight or desktop-wide via Espanso.

    note ...todo add;sig{clipboard}
    🔐

    Secure Clipboard Vault & Paste Queue

    Encrypt pinned text and PNG images with Argon2id + XChaCha20-Poly1305. Pins auto-expire in 1 hour, copy with sensitive metadata + 30s timeout, and stream sequentially through an in-memory Paste Queue.

    vaultclip pinnedclip queue0600
    ⚡

    Visual No-Code WASM Workflows

    Build 1–12 step chains visually—like Screenshot → OCR → Translate Locally → Save Note—compiled into genuine import-free binary .wasm modules executed inside Wasmi with a 10,000-fuel cap.

    workflowworkflow runWasmi0 imports
    🧠

    Context-Aware Local AI (Ollama)

    Ask questions about your selected project, open KWin windows, and todos.md—or summarize your clipboard—using verified loopback-only Ollama (OLLAMA_NO_CLOUD=1) with an exact snapshot preview before sending.

    ai askai summarize clipboard127.0.0.1
    🌿

    Git Dashboard, IDE Projects & GitHub

    Reopen recent VS Code, VSCodium, and JetBrains projects, set active project context, inspect all dirty Git repositories under ~/Projects, clone repos, and browse open GitHub PRs and issues.

    git statuscodejetbrainsgh pr list

    Docker/Podman Logs, HTTP Scratch & Dotenv

    Start/stop containers, live-tail logs inside Spotlight, launch interactive container shells, test REST endpoints with pretty JSON in HTTP Scratch, diff .env vs .env.example, and open SSH aliases in Konsole.

    docker logsdocker execget https://dotenv diff

    WASM Extension Store & Generators

    Browse community-plugins.toml and install SHA-256 verified WASM plugins, or run custom scripts. Includes offline UUID, SHA/MD5 hashing, Base64, JSON formatter, case converter, Lorem Ipsum, QR codes, and OCR.

    storeuuidjson formatqr hello

    Screenshot, Image, PDF & Color Toolkit

    Capture via desktop portal with instant OCR, QR decode, compress, and pin actions. Compress to WebP, resize to 1080p, extract 5-color palettes, extract PDF text, pick screen colors (HEX/RGB/HSL), and measure pixels with a multi-monitor ruler.

    screenshotpalettepdf textmeasure

    Quick Start · 3 Minutes

    Install Spotlight on your Linux distro

    Build natively as your normal user—no sudo needed during install.

    1 Install dependencies (or install directly with Nix) 
    
              
            
    
          
    

          
    
            
    
              2
              Clone, build, and launch (requires stable Rust)
            
    
            
    
              
    git clone https://github.com/danny19862025/spotlight.git
cd spotlight
cargo fetch --locked
sh install.sh
"$HOME/.local/bin/spotlight"
    
              
            
    
          
    

          
    
            
    
              3
              Bind Meta+Space on KDE & enable optional login autostart
            
    
            
    
              
    ~/.local/bin/spotlight --install-shortcut
~/.local/bin/spotlight --autostart
