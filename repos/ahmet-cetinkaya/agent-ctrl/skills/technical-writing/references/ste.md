# Simplified Technical English (ASD-STE100)

The writing rules of ASD-STE100, applied as the default English prose style. The STE dictionary is a guide to word choice, not a word-by-word gate; it is not bundled here.

## Sentences

- One instruction per sentence, in the imperative: "Run the migration", not "The migration should then be run".
- At most 20 words in a procedure step, 25 in descriptive text, six sentences in a paragraph.
- Active voice and present tense. Keep the articles (`the`, `a`).
- No `-ing` verb form where a simple verb works. No noun cluster longer than three words.

## Words

- One term for one thing, used the same way everywhere. Do not alternate synonyms for variety.
- Prefer the short common word: `use`, not `utilize`; `make sure`, not `ensure`; `start`, not `initiate`.
- No idioms, slang, or figures of speech.

## Structure

- A warning or caution comes before the step it protects.
- A sequence is a numbered list; a set of options is a bulleted list.
- Say the condition before the action: "If the build fails, open the log", not "Open the log if the build fails".

## Where STE yields

- Audience-specific tone set by a command (for example benefit-driven release notes) stays; STE shapes the sentences, not the message.
- Developer-facing reference text keeps precise technical terms the dictionary would not approve.
