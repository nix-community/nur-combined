# Risk Triggers

Increase review and verification when a change touches:

- identity, session, authentication, authorization, roles, tenancy, or permission boundaries;
- user-controlled text, files, URLs, queries, templates, commands, or deserialization;
- secrets, tokens, credentials, encryption keys, signing, or credential transport;
- personal, regulated, financial, or otherwise sensitive data;
- database schema, migration, retention, deletion, backup, import, or export;
- public, partner, webhook, plugin, or shared internal API contracts;
- package acquisition, build scripts, artifact publication, CI credentials, infrastructure, or deployment;
- irreversible operations or partial-state failure.

State affected assets, threat actors, boundary crossings, abuse/failure scenarios, controls, rollback, and residual risk. Keep checks proportional to actual exposure.
