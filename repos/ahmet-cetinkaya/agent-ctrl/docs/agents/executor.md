# `executor` composition

- **Target and responsibility:** Gate and feedback executor for `/ac:verify` runs and `/ac:pr-address` fixes, with verified delegation and risk gates. Plan execution moved to the main session (see `docs/commands/run.md`).
- **Sources:** [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) Atlas agent, plan start, delegation, and verification behavior; current [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) `packages/omo-opencode/src/agents/atlas/AGENTS.md`, “Key behaviors”; current [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) `packages/shared-skills/skills/ulw-execute/SKILL.md`, dependency, evidence, and done-claim discipline.
- **Behavior taken:** opt-in local commits chosen at plan approval (`commits: none | per-task | per-phase`, default `none`), adapted from the ulw-plan Commit strategy and per-todo Commit line: committed only by the session running `/ac:run`, serialized, write-set staging, hooks honored, hashes in the ledger; a resumable run state under `.agents/work/<id>/` (state, append-only notepad, JSONL ledger, captured evidence) adapted from Boulder, Atlas notepads, and the ulw-execute ledger, with the orchestrator as its only writer; approved-plan start, in-progress or resolved-blocked resume, completed-plan rejection, lifecycle transitions, dependency-aware execution, declared disjoint write sets, Atlas's no-self-implementation rule so verification stays independent, stub and placeholder checks on changed files, a four-dimension final pass (compliance, quality, real-surface QA, scope fidelity), self-contained worker handoff, parent inspection, and final verification.
- **Merge:** Current OMO's strong execution accounting is reduced to a portable task/evidence contract and combined with Atlas's no-redesign boundary.
- **Provider adaptation:** Canonical `Task` appears in source tools and is rendered for OpenCode; plans use `.agents/work/<slug>/plan.md`, require `status: approved`, and use no runtime-specific state. Claude Code alone routes this verification-heavy role to `opus` through `models.claude`.
- **Exclusions:** Boulder's session-ID schema and continuation hook, forced worktrees, mandatory delegated QA, automatic PR/merge lifecycle, provider categories, and OpenCode call syntax were omitted.
