# `planner` composition

- **Target and responsibility:** Spec writer for `/ac:spec` that returns clarifying questions to its caller and writes one behavior spec. Plan writing moved to the main session through `/ac:plan`, because discovery, interview, and plan build on each other and subagents cannot ask the user; the `evals/ac` plan-then-run comparison showed equal hidden-test results.
- **Sources:** [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) Prometheus agent, interview-first, bounded exploration, one-plan, and boundary behavior; [SuperClaude Framework](https://github.com/SuperClaude-Org/SuperClaude_Framework) `src/superclaude/agents/requirements-analyst.md`, requirements and acceptance analysis sections; [Everything Claude Code](https://github.com/affaan-m/ECC) `skills/intent-driven-development/SKILL.md`, “When to Activate,” acceptance criteria, and handoff; current [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) `packages/shared-skills/skills/ulw-plan/SKILL.md`, decision-complete planning and approval boundaries.
- **Behavior taken:** A recommended `commits` strategy asked only for multi-task or phased plans; Repo-first discovery, few non-discoverable questions, a human Summary first, a handoff that names task count and anything added beyond the request, explicit decisions, per-task evidence, `draft → approved` lifecycle, and no implementation.
- **Merge:** Requirements and planning personas are consolidated into one role backed by `work-planning` rather than separate spec stages.
- **Provider adaptation:** Plan storage moved from provider-private paths to `.agents/work`; `status: draft` is written first and only explicit approval makes it executable; only canonical `Task` delegation to three read-only roles is described. Claude Code alone routes this decision-heavy role to `opus` through `models.claude`.
- **Exclusions:** OMO draft/Boulder state, OpenCode invocation examples, mandatory interview ceremony, stale spec namespaces, and cross-platform model pins were excluded.
