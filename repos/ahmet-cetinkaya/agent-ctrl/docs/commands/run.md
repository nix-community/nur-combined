# `/ac:run` composition

- **Target and responsibility:** Execute an approved plan or already-clear scoped request without Git delivery.
- **Sources:** [SuperClaude Framework](https://github.com/SuperClaude-Org/SuperClaude_Framework) `src/superclaude/commands/implement.md`, standalone implementation and existing-convention flow; [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) Atlas agent, faithful plan execution; current [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) `packages/shared-skills/skills/ulw-execute/SKILL.md`, dependency and evidence discipline.
- **Behavior taken:** opt-in local commits chosen at plan approval (`commits: none | per-task | per-phase`, default `none`), adapted from the ulw-plan Commit strategy and per-todo Commit line: committed only by the session running `/ac:run`, serialized, write-set staging, hooks honored, hashes in the ledger; run-state creation and resume under `.agents/work/<id>/`, ledger-recorded checks, approved-plan start, in-progress or resolved-blocked resume, draft/completed/ambiguous rejection, clear-input gate for direct requests, executor handoff, dependency-aware completion, evidence validation, and risk review.
- **Merge:** Multiple implement/ship/start-work paths become one execution command backed by `plan-execution`. Plan execution was folded out of the executor and worker chain into the main session, with workers only for parallel task batches and independent review at risk boundaries and `/ac:verify`, per Anthropic's [When to fold subagents into your main agent loop](https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop); the `evals/ac` comparison showed equal hidden-test results at about half the cost and wall time.
- **Provider adaptation:** Agent names and plan path are shared across Claude/OpenCode; no provider task-call syntax is embedded.
- **Exclusions:** Commits the approved plan did not opt into, worktrees, push/PR/merge, maximum parallelism, stale command chains, and plan redesign were excluded.
- **Attribution:** Original rewrite drawing on [SuperClaude Framework](https://github.com/SuperClaude-Org/SuperClaude_Framework) (MIT) and [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) (Sustainable Use License); no upstream prose is copied verbatim.
