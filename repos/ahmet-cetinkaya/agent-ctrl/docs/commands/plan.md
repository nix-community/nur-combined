# `/ac:plan` composition

- **Target and responsibility:** Explicit checkpoint for creating, but not executing, one decision-complete plan.
- **Sources:** [SuperClaude Framework](https://github.com/SuperClaude-Org/SuperClaude_Framework) `src/superclaude/commands/brainstorm.md`, ambiguity discovery; [Everything Claude Code](https://github.com/affaan-m/ECC) `skills/intent-driven-development/SKILL.md`, acceptance criteria and scope; [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) Prometheus agent, one-plan boundary; current [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) `packages/shared-skills/skills/ulw-plan/SKILL.md`, explore-first planning.
- **Behavior taken:** Conditional design artifacts beside the spec (`research.md`, `data-model.md`, `contracts/`) after spec-kit's plan phases, with `quickstart.md` left to the plan's QA and `/ac:verify`; A `commits` strategy (default `none`) recorded for later execution; Repository discovery, decision completion, a mandatory gap analysis (independent for a Full Brief) and an automatic `/ac:plan-review` review on a high-accuracy request or a defaulted fuzzy outcome, following the ulw-plan Metis and high-accuracy steps, a handoff naming task count and additions beyond the request, durable `status: draft` plan, explicit approval transition, evidence per task, and no implementation, plus local user-requested optional phased delivery (an umbrella branch with phase PRs, chosen by the user and proposed only).
- **Merge:** Legacy brainstorm/spec/plan stages collapse into one command that activates `work-planning` and routes to `planner`. A spec is an optional upstream artifact: when `/ac:spec` has produced an approved spec, `/ac:plan <spec-path>` derives the plan from it and adds a Traceability table (see `docs/commands/spec.md`).
- **Provider adaptation:** Uses `.agents/work` instead of provider-private plan or draft paths and contains no invocation-specific syntax.
- **Exclusions:** Mandatory spec artifacts (the spec stage is opt-in through `/ac:spec`), stale namespaces, approval machinery for writing drafts, implementation handoff commands, and provider runtime state were omitted.
- **Attribution:** Original rewrite drawing on [SuperClaude Framework](https://github.com/SuperClaude-Org/SuperClaude_Framework) (MIT), [Everything Claude Code](https://github.com/affaan-m/ECC) (MIT), and [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) (Sustainable Use License); no upstream prose is copied verbatim.
