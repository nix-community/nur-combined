# Command composition index

The only command namespace is `ac`, containing twelve commands: `spec`, `plan`, `plan-review`, `run`, `fix`, `research`, `review`, `verify`, `doc`, `changelog`, `pr`, and `pr-address`. Each record in this directory explains the legacy behavior retained, its skill-based composition, provider adaptation, exclusions, and attribution. These docs stay outside `commands/` because its scanner treats every Markdown file as a command.
