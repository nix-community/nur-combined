# `/ac:plan-review` composition

- **Target and responsibility:** Independent read-only adversarial validation of a plan's decisions, feasibility, dependency graph, safety, rollback, and evidence.
- **Sources:** current `risk-review`, `advisor`, `work-planning`, and `secure-engineering` contracts; current [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) `packages/shared-skills/skills/ulw-plan/references/full-workflow.md`, bounded convergence, and `packages/omo-opencode/src/agents/momus.ts`, blocker-only rejection.
- **Behavior taken:** [spec-kit](https://github.com/github/spec-kit) `templates/commands/analyze.md` detection passes over spec and plan (duplication, ambiguity, underspecification, unbuilt success criteria, terminology and entity drift, conflicts, order); Assumption busting, repository/external fact checking, dependency/write-set analysis, risk and rollback review, verification challenge, concrete amendments, a two-lane review — executability (Momus) checks run directly by the orchestrator and one adversarial (Oracle) `advisor` session, with two independent sessions only under `--deep` or an explicit high-accuracy request (a risk boundary only prompts a `--deep` suggestion), both lanes required to pass, and re-reviews continuing the same session to save quota — with receipts bound to the plan's SHA-256 digest in the run state, evidence-based blocker eligibility, non-blocking notes that still pass, a frozen re-validation scope, a three-round cap, and residual-risk reporting.
- **Merge:** Renamed from `plan-validate` because the command is an adversarial review with a verdict, not a mechanical validation. The old red-team hub becomes a read-only structured verdict using explorer/researcher/advisor instead of retired personas and councils.
- **Provider adaptation:** Plain agent/skill routing replaces persona metadata and provider syntax.
- **Exclusions:** Pseudo-precise 95% confidence threshold, automatic plan rewrites/status changes, fixed three-round ceremony, the descriptor-level path binding and compare-and-swap lane state machine, and plan-estimate dependency.
- **Attribution:** Original rewrite drawing on [oh-my-openagent](https://github.com/code-yeongyu/oh-my-openagent) (Sustainable Use License); no upstream prose is copied verbatim.
